# İndirim Avcısı

Агрегатор скидок турецких магазинов. Сайт: https://prostoyy17.github.io/Discounts/

## Как работает

GitHub Actions (`.github/workflows/pages.yml`) дважды в день (06:12 и 18:12 по Турции), при каждом пуше
в `master` и по кнопке **Run workflow**:

1. `npm test` — тесты парсера на сохранённых страницах BİM (`test/fixtures/`).
2. `npm run crawl:bim` — обходит все даты «Aktüel» и раздел «İndirim» на bim.com.tr (пауза 2 с между
   запросами, честный User-Agent с контактом), проверяет каждую карточку, пишет `site/data/bim.json`.
3. `npm run verify:bim` — независимая сверка: для случайной выборки открывает страницу самого товара и
   сравнивает название, цену, старую цену, id; проверяет, что фото открывается.
4. Публикует `site/` на GitHub Pages.

Если хоть одна проверка не прошла, деплоя нет и на сайте остаётся прошлая рабочая версия.

## Проверки (`src/validate.js`)

- каждая карточка на странице превратилась в товар (ничего не потеряно молча), нет дублей;
- есть id, название без HTML-мусора, цена > 0;
- у скидки старая цена больше новой, и процент на сайте совпадает с расчётом (±1);
- фото только с `cdn*.bim.com.tr`, ссылка только на `www.bim.com.tr`;
- дата периода распознана (с учётом перехода через Новый год);
- обход отклоняется целиком, если товаров < 50 или битых > 2 %.

## Локально

```
npm install
npm test
npm run crawl:bim                      # нужен интернет
npm run crawl:bim -- --from-dir .cache # офлайн из сохранённых страниц (index.html + p<key>.html)
npm run verify:bim -- --sample 24      # или --all
npm run serve                          # http://localhost:8080
```

## Правила сбора

- Не обходим защиту от ботов (Cloudflare, капчи) — никогда.
- Соблюдаем robots.txt, паузы между запросами, обход не чаще пары раз в день.
- Берём минимум: бренд, название, вес/объём, цену, период. Длинные описания не берём.
- Фото не копируем к себе — показываем по ссылке с сайта магазина.
- Каждая карточка ведёт на страницу товара в магазине, источник указан на сайте.
- Попросят убрать — убираем.
